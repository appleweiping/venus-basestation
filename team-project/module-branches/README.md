# Module Branch Snapshots

These folders preserve public-safe snapshots of Team 28 GitLab module branches so the GitHub archive shows the complete team project context, not only Vipin's UI module.

- `communication-module/` - MQTT and UART communication tests/prototypes.
- `algorithm-navigation-module/` - navigation/motion application code from the algorithm branch.
- `embedded-software-module/` - embedded sensor and template work from the embedded branch.
- `mapping-new/` - mapping/navigation branch with mapping, communication, and sensor-handler integration files.

The original GitLab repository remains the collaborative source of truth. These snapshots exclude `.git/` metadata and personal `sftp.json` files.
